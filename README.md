# Daily bioRxiv AI Enhanced

This tool daily crawls https://www.biorxiv.org for papers related to **molecular dynamics** and **machine learning**, and uses LLMs (Cloudflare Workers AI) to summarize them.

## Quick Start

1. Fork this repo
2. Set up GitHub Secrets: `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN`
3. Set up GitHub Variables: `KEYWORDS`, `LANGUAGE`, `MODEL_NAME`, `EMAIL`, `NAME`
4. The workflow runs daily at 04:00 UTC, or trigger it manually
